# URL Shortener - Serverless

A full-stack serverless URL shortener built with React, TypeScript, AWS Lambda, DynamoDB, and CloudFormation.

## Architecture

- **Frontend:** React 18 + TypeScript + Tailwind CSS (deployed to S3/CloudFront)
- **Backend:** Node.js Lambda functions + API Gateway
- **Database:** DynamoDB (single-table design)
- **Infrastructure:** CloudFormation (Infrastructure as Code)

## Tech Stack

- React 18
- TypeScript
- AWS Lambda (Node.js 20)
- API Gateway
- DynamoDB
- CloudFormation
- Vite
- Tailwind CSS
